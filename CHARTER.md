# CSCI 2020U Project Charter & Work Contract

## 1. Project Overview

* **Project Members:** Rahil Sanketbhai Vaghasia, Krisha Kandoi

* **Product Name:** TaskFlow – Shared Task Manager

* **Project Description:**  
TaskFlow is a multi-user client-server task management application designed for both professional and personal use. Managers can assign tasks to employees, track progress, and manage deadlines, while employees can update task status and add notes. In addition, each user can create personal folders to manage private tasks separately from team tasks.  
The system supports continuous server operation, allowing multiple clients to connect at any time and access shared data. Enhanced features include task filtering, priority levels, and a clean user interface for better user experience.

* **Tech Stack:**  
Programming Language: Java  
GUI Framework: Java Swing  
Networking: Java Sockets (Client-Server Communication)  
Concurrency: Multi-threading (to handle multiple clients simultaneously)  
Persistence: File I/O (or simple local storage for saving tasks)  
Optional Enhancement: Real-time updates using multi-threaded server handling multiple clients
